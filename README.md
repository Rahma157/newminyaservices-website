# خدمات المنيا الجديدة — New Minya Services

منصة رقمية تجمع كل الخدمات والأماكن المهمة في مدينة المنيا الجديدة: اكتشاف، بحث، حجز، متابعة عروض وأخبار، والتواصل مع مقدمي الخدمات.

مشروع تخرج جامعي — واجهة أمامية (Front-End) كاملة، بدون أي اتصال بقاعدة بيانات فعلية (كل البيانات تجريبية Static).

---

## 🛠️ التقنيات المستخدمة
- HTML5
- CSS3 (متغيرات CSS / Flexbox / Grid)
- JavaScript (Vanilla — بدون أي مكتبات JS إضافية غير المذكورة)
- Bootstrap 5.3 (الشبكة Grid وبعض المكوّنات مثل الـ Carousel)
- Bootstrap Icons
- Font Awesome 6

## 🎨 نظام التصميم
- **الألوان:** أخضر نخيلي غامق `#0F4C3A` كلون أساسي، مع رمل دافئ `#F7F4EC` كخلفية، ولمسة ذهبية تراثية `#B8903D` للعناصر المميزة.
- **الخطوط:** Cairo للعناوين، Tajawal للنصوص — عبر Google Fonts.
- **الاتجاه:** RTL بالكامل مناسب للغة العربية.
- **العنصر المميز:** شريط بحث عائم أسفل قسم الهيرو، وفواصل زخرفية مستوحاة من سعف النخيل.

## ▶️ طريقة التشغيل
1. فك ضغط المجلد.
2. افتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome / Edge / Firefox).
3. لا حاجة لأي خادم أو تثبيت — الموقع Static بالكامل.

> ملاحظة: الصور مستخدمة عبر روابط خارجية من Unsplash، لذا يلزم اتصال بالإنترنت لعرضها بجودة كاملة. يمكن استبدالها بصور محلية داخل مجلد `images/` وتحديث المسارات في ملفات HTML عند الحاجة.

## ✨ أبرز الميزات
- تصميم Modern UI/UX متجاوب بالكامل (موبايل / تابلت / كمبيوتر).
- بحث وفلترة فورية للخدمات بدون إعادة تحميل الصفحة.
- نظام حجز تفاعلي (Modal) مع التحقق من صحة البيانات ورسالة نجاح.
- نماذج تسجيل دخول وإنشاء حساب مع Validation بالكامل عبر JavaScript.
- Scroll Reveal، Hover Effects، Smooth Scrolling، وشاشة تحميل بسيطة.
- كود منظم ومقسم لكل صفحة/ملف مستقل مع تعليقات توضيحية.

## 👥 فريق المشروع
مشروع تخرج جامعي — يمكن تعديل بيانات الفريق من داخل صفحة `about.html`.
